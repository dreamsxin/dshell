# dshell 界面设计方案

> 状态：设计定稿，待实施
> 适用范围：`dshell` 桌面客户端全部界面（会话、终端、文件传输、转发、设置）
> 技术前提：Rust + GPUI + gpui-component，原生渲染，不使用 WebView

---

## 1. 目标与范围

### 1.1 目标

1. 建立统一的视觉语言：颜色、间距、圆角、字号、动效全部来自设计令牌，不在业务代码里写魔法值。
2. 建立组件层：侧边栏条目、标签页、面板头、表单字段、模态框、提示条等只实现一次。
3. 重排信息层级：让"连接 → 终端 → 传输/转发"这条主路径在一屏内可完成，且不打断终端输入焦点。
4. 保持键盘优先：所有高频操作有快捷键，焦点可见，弹层可用键盘关闭。
5. 为后续功能（日志时间线、多级跳板、密钥管理、主机指纹管理）预留稳定的布局插槽。

### 1.2 不在本期范围

- 终端内部的 VT 渲染逻辑（由 `alacritty_terminal` 承载，仅调整配色与光标绘制）。
- 主题市场的下载/安装机制（本期只做内置主题）。
- 移动端或 Web 端适配。

### 1.3 硬约束

- 原生 UI，禁止引入 WebView / Electron / Tauri / Wry。
- 终端帧仍由 GPUI 按 16 ms 批次渲染，UI 改动不得改变 SSH 线程与终端状态机的职责边界。
- 任何视觉改动都不得降低既有安全约束（不落盘密码、严格 `known_hosts` 校验）。

## 2. 现状盘点

当前界面主体集中在 `src/main.rs`（约 6300 行），已具备以下能力，但缺少统一抽象：

- 侧边栏：已保存主机、最近连接、收藏、配置文件导入。
- 会话：多标签、双栏分屏、重连、断开、关闭、Alt+1..9 切换。
- 终端：主题（Default / Solarized Dark / Solarized Light）、光标样式、搜索、日志回放。
- 传输：SFTP 双栏浏览、上传下载、断点续传、覆盖确认。
- 转发：本地/远程端口转发规则与持久化。
- 设置：字号、字体、主题、快捷键、密钥生成。

问题集中在四处：

1. 尺寸、颜色、间距散落在各 `render_*` 函数中，改一处需要全局搜索。
2. 同类控件（按钮、输入框、面板头、空状态）在不同面板里样式不一致。
3. 面板与模态框没有统一的层级、遮罩、关闭行为。
4. 侧边栏、标签栏、状态栏缺少明确的视觉分区，信息密度偏高。

---

## 3. 设计原则

| 原则 | 落地方式 |
| --- | --- |
| 终端优先 | 终端区域永远占据最大面积；侧栏与检查器可折叠；任何弹层关闭后焦点回到终端 |
| 一眼可辨 | 连接状态用颜色 + 图形 + 文案三重表达，不只依赖颜色 |
| 克制的层次 | 仅用背景明度差、1px 描边、轻阴影区分层级，避免重边框与强渐变 |
| 8px 网格 | 所有间距、控件高度、图标尺寸为 4 的倍数，主间距为 8 的倍数 |
| 键盘可达 | 焦点环统一 2px；`Esc` 关闭弹层；`Tab` 顺序与视觉顺序一致 |
| 动效有节制 | 仅用于层级变化与状态切换，120–180 ms，尊重系统"减少动效"偏好 |

## 4. 参考产品的界面观察（脱敏）

调研了主流 SSH 终端客户端的公开文档与截图，归纳出可复用的结构，不复制其品牌元素：

- 顶部为**会话级工具条**，放连接、复制、发送文件、分屏等高频动作，而不是应用级菜单。
- 左侧为**会话管理器**，树形分组 + 搜索框 + 最近连接，宽度可调。
- 中部为**标签式终端区**，标签自带连接状态点与关闭按钮。
- 右侧/底部为**可折叠检查器**，承载传输队列、转发规则、连接信息。
- 底部**状态栏**显示连接名、加密算法、终端尺寸、传输速率。
- 设置与属性使用**独立模态窗口**，左侧分组、右侧表单。

本方案沿用这一信息架构，但视觉上采用更现代的扁平卡片风格。

## 5. 设计令牌

实现位置：`src/ui/theme.rs`，导出 `ThemeTokens` 与语义化访问器。业务代码只引用语义名（如 `tokens.surface_raised`），不引用具体色值。

### 5.1 颜色

浅色与深色两套，均满足正文对比度 ≥ 4.5:1。

| 语义名 | 用途 | 深色 | 浅色 |
| --- | --- | --- | --- |
| `bg_canvas` | 应用底色 | `#0F1115` | `#F5F6F8` |
| `surface` | 侧栏、状态栏 | `#15181E` | `#FFFFFF` |
| `surface_raised` | 卡片、面板 | `#1B1F27` | `#FFFFFF` |
| `surface_overlay` | 模态、浮层 | `#20252F` | `#FFFFFF` |
| `border_subtle` | 分隔线 | `#262C36` | `#E4E7EC` |
| `border_strong` | 输入框、卡片描边 | `#333B48` | `#D0D5DD` |
| `text_primary` | 主文本 | `#E7EAF0` | `#101828` |
| `text_secondary` | 次要文本 | `#A0A9B8` | `#475467` |
| `text_disabled` | 禁用 | `#5C6575` | `#98A2B3` |
| `accent` | 主操作、选中 | `#3B82F6` | `#2563EB` |
| `accent_hover` | 悬停 | `#60A5FA` | `#1D4ED8` |
| `success` | 已连接 | `#22C55E` | `#16A34A` |
| `warning` | 重连中、覆盖确认 | `#F59E0B` | `#D97706` |
| `danger` | 错误、删除 | `#EF4444` | `#DC2626` |
| `focus_ring` | 焦点环 | `#60A5FA` | `#2563EB` |

终端配色独立于 UI 主题，沿用现有 `TerminalTheme` 三套调色板；UI 深色/浅色与终端主题互不强制绑定。

### 5.2 间距

`space_1 = 4`、`space_2 = 8`、`space_3 = 12`、`space_4 = 16`、`space_5 = 24`、`space_6 = 32`。

规则：卡片内边距 16，控件内边距 8×12，同级控件间距 8，分组间距 24，页面外边距 16。

### 5.3 尺寸

| 元素 | 高度/宽度 |
| --- | --- |
| 命令条 | 52 |
| 侧边栏 | 248（可拖拽 200–360） |
| 检查器 | 380（可拖拽 300–520） |
| 标签栏 | 40 |
| 状态栏 | 28 |
| 输入框 / 小按钮 | 28 |
| 常规按钮 | 32 |
| 主操作按钮 | 36 |
| 图标 | 16（行内）/ 20（工具条） |
| 列表行 | 56 |

### 5.4 圆角与描边

- 圆角：输入框/按钮 6，卡片 8，面板 12，模态 12，胶囊 999。
- 描边：默认 1px `border_subtle`；获得焦点 2px `focus_ring`。
- 阴影：仅模态与浮层使用，`0 12px 32px rgba(0,0,0,0.28)`（浅色主题降到 0.12）。

### 5.5 字体

- UI：随 `font_family` 设置，默认系统无衬线；字号 12/13/14/16/20，正文 13。
- 终端：等宽字体，字号由设置控制（9–32），行高 = 字号 × 1.35。
- 数字对齐使用等宽数字特性，避免速率、尺寸跳动。

### 5.6 动效

- 面板展开/收起：160 ms ease-out，宽度或高度过渡。
- 标签切换：120 ms 透明度过渡，不做位移。
- 模态出现：140 ms 缩放 0.98 → 1.0 + 透明度。
- 连接状态点：连接中呼吸动画 1.2 s，连接成功停止。

### 6.1 命令条

- 左区：新建会话（主按钮）、分屏、搜索会话。
- 中区：当前会话名与连接状态胶囊（连接中/已连接/已断开）。
- 右区：主题切换、设置、窗口控制（由系统提供）。
- 连接中显示"取消"，已断开显示"重连"。

### 6.2 侧边栏

- 顶部固定搜索框，占位符"搜索会话、主机或标签"。
- 分组顺序：收藏 → 最近连接（最多 8 条）→ 已保存主机（可分组）。
- 每行：状态点、别名（主）、`user@host:port`（次），悬停显示"连接/编辑/更多"。
- 底部固定两个入口：导入配置、新建主机。
- 折叠后仅保留 48px 图标列；`Ctrl+Shift+B` 切换。

### 6.3 标签栏

- 每个标签：状态点、标题、可选分屏图标、关闭按钮。
- 已保存会话可设置自定义标题和颜色；标题留空时显示会话名称，颜色作为顶部强调线并适配当前主题。
- 未指定标签颜色时，选中标签使用主题强调色；选中标签使用 `surface_raised` 背景与 2px 顶部强调线。
- 标签溢出时左右滚动，不做多行。
- 标签可拖拽排序；分屏标签显示状态点、标题、分屏标记和关闭按钮。

### 6.4 终端卡片

- 卡片与窗口边缘留 8px，圆角 12，`surface_raised` 背景。
- 顶部 32px 悬浮工具条：搜索、清屏、复制、粘贴、日志回放、发送文件、更多；悬停出现，30% 透明直到鼠标进入。
- 终端内容使用终端主题背景，卡片描边不覆盖内容区。
- 分屏时每个面板独立圆角，中间 1px 分隔条可拖拽（最小 160px）。

### 6.5 检查器

- 三个可折叠分组：传输队列、转发规则、连接信息。
- 传输队列：文件名、方向图标、进度条、速率、暂停/取消。
- 转发规则：类型、监听地址、目标地址、启用开关。
- 连接信息：主机指纹、加密算法、认证方式、会话时长、终端尺寸。
- 无内容时显示空状态（图标 + 一句话 + 主操作）。

### 6.6 组合输入栏

- 默认收起；`Ctrl+Shift+M` 展开，高度 96px。
- 多行输入，`Ctrl+Enter` 发送，支持在发送前编辑历史。
- 展开时不抢占终端选中文本。

### 6.7 状态栏

- 左：连接状态点 + 会话名 + 状态文案。
- 中：加密算法、终端尺寸。
- 右：吞吐量、当前时间（可关闭）。

## 7. 组件清单

新增 `src/ui/components.rs`，每个组件接收 `&ThemeTokens` 与数据，不直接读全局状态。

| 组件 | 说明 | 状态 |
| --- | --- | --- |
| `SidebarItem` | 图标 + 主标题 + 副标题 + 右侧动作 | 默认/悬停/选中/禁用 |
| `SessionTab` | 状态点 + 标题 + 关闭 | 默认/悬停/选中/连接中 |
| `PanelHeader` | 标题 + 折叠箭头 + 右侧动作 | 展开/收起 |
| `Field` | 标签 + 输入 + 帮助文本 + 错误文本 | 默认/聚焦/错误/禁用 |
| `Modal` | 标题 + 内容 + 底部按钮 + 遮罩 | 打开/关闭 |
| `Toast` | 图标 + 文本 + 关闭 | info/success/warning/error |
| `Pill` | 状态胶囊 | 各语义色 |
| `EmptyState` | 图标 + 标题 + 说明 + 操作 | — |
| `ProgressBar` | 传输进度 | 进行中/暂停/失败/完成 |
| `IconButton` | 20px 图标按钮 | 默认/悬停/按下/禁用 |
| `SplitDivider` | 可拖拽分隔条 | 水平/垂直 |

统一交互规格：

- 按钮高度 28/32/36 三档，水平内边距 12，图标与文字间距 6。
- 悬停背景 = 当前 surface 提亮 6%；按下提亮 10%。
- 禁用态降低不透明度至 0.45，不改变布局。
- 焦点环绘制在元素外侧，不改变尺寸。

## 8. 弹层规范

| 弹层 | 尺寸 | 行为 |
| --- | --- | --- |
| 新建/编辑会话 | 720×640 | 左侧分组导航，右侧表单；`Esc` 取消，`Ctrl+Enter` 保存 |
| 设置 | 760×600 | 分组：外观、终端、快捷键、密钥、关于 |

| 认证提示（OTP/交互） | 480×auto | 逐项输入，密码类字段可切换明文，提交后清空 |

弹层通用行为：点击遮罩关闭（危险操作除外）、`Esc` 关闭、打开时锁定背景滚动、关闭后焦点归还触发元素。

## 9. 代码组织

```
src/ui/
├── mod.rs          # 导出 tokens / components / layout
├── theme.rs        # 设计令牌与色板映射
├── tokens.rs       # 间距、尺寸、圆角、动效常量
├── components.rs   # 通用组件
├── layout.rs       # 应用外壳：命令条、侧栏、标签栏、状态栏
├── panels.rs       # 侧栏内容、检查器、传输与转发面板
└── dialogs.rs      # 会话编辑、设置、确认、认证提示、密钥生成
```

拆分原则：

- `main.rs` 保留状态与事件处理，渲染函数逐步迁移到 `ui/` 并改为接收不可变数据。
- 组件不持有业务状态，回调以闭包形式传入。
- 所有尺寸/颜色只能来自 `ThemeTokens`，代码评审中禁止新增裸色值。

## 10. 分阶段实施

- 新增 `src/ui/theme.rs`、`tokens.rs`、`components.rs`。

- 验收：`cargo test` 与硬约束脚本通过；设置面板无裸色值。

- 验收：1280×800 与 1920×1080 下无重叠、无截断；折叠/展开状态持久化。

### 阶段 3：会话与主机管理

- 侧边栏分组、搜索过滤、悬停动作、空状态。

- 验收：新增/编辑/删除/收藏全流程纯键盘可完成。

### 阶段 4：终端工具条与检查器

- 终端悬浮工具条、搜索条统一、日志回放外观统一。
- 检查器接入传输队列、转发规则、连接信息。
- 验收：传输/转发状态变化在 200 ms 内反映；检查器折叠不改变终端尺寸计算错误。

### 阶段 5：弹层与反馈

- 统一模态、确认框、认证提示、密钥生成、Toast。

### 阶段 6：打磨与验证

- 深色/浅色主题全量走查，对比度检查。
- 多 DPI（100%/150%/200%）与字体缩放验证。
- Windows 中文输入法、终端选中、快捷键冲突回归。
- 验收：59 项单元测试与 9 项容器集成测试保持通过；更新 `IMPLEMENTATION_STATUS.md`。

## 12. 风险与对策

| 风险 | 对策 |
| --- | --- |
| GPUI 组件能力不足（如滚动吸顶、虚拟列表） | 先用固定高度 + 手动裁剪实现，必要时在 `ui/` 内封装替代方案 |
| 大文件 `main.rs` 拆分引入回归 | 按面板逐个迁移，每步跑测试并提交，保持可回滚 |
| 自绘控件导致输入法异常 | 输入统一走 `InputState`，不自绘文本光标与候选框 |
| 主题切换引起终端闪烁 | 主题变更只更新调色板并重绘当前帧，不重建会话 |
| 折叠动画与终端尺寸计算竞态 | 动画结束后统一触发一次 `resize_sessions` |
