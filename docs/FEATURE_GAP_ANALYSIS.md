## 三、UI 优化建议

### 布局优化

- **地址栏**：工具栏添加地址输入框，Alt+D 聚焦
- **面板停靠**：侧栏/检查器添加自动隐藏
- **标签组**：多组并排，每组显示一个标签
- **工作区预设**：Focus/Standard/Inspector 预设按钮
- **终端侧边栏**：可停靠的 SFTP/转发/日志面板

### 终端体验优化

- **关键词高亮**：内置规则 + 自定义正则
- **保存屏幕**：右键菜单添加"保存可见文本"
- **动态标题**：OSC 0/2 序列更新标签
- **多行粘贴确认**：保护网络设备 CLI
- **终端搜索高亮**：匹配高亮
- **广播模式**：广播模式开关按钮
- **自动重连**：断线自动重连
- **光标行高亮**：WindTerm 风格

### 主机管理优化

- **主机图标**：自动检测发行版图标
- **主机备注**：每个主机可附加备注
- **连接测试**：主机详情中测试连接
- **导入导出**：CSV 导出
- **框选选择**：鼠标框选多个主机

### 视觉与主题优化

- **自定义主题编辑器**：自定义调色板
- **字体连字**：支持 ligatures
- **CJK 字体**：CJK 字体专门支持
- **窗口透明度**：窗口透明切换
- **光标样式**：闪烁、条形宽度
